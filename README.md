# Writer Studio

ИИ-помощник для писателей в Obsidian: локальные и облачные модели, чаты с персонажами, перевод и инструменты для работы с текстом.

Writer Studio помогает работать над книгами и другими текстами прямо в хранилище Obsidian. Плагин может подключаться к локальным нейросетям или облачным сервисам — выбор остаётся за пользователем.

> Плагин находится в разработке. Возможности и интерфейс могут меняться.

## Возможности

### Чаты

В плагине есть несколько способов работать с нейросетью:

- **Чат** — обычный диалог с возможностью подключать заметки и папки как контекст.
- **Чат с персонажем** — диалог с выбранным персонажем. Его описание и системный промпт можно редактировать.
- **Круговорот** — обсуждение задачи несколькими персонажами под руководством модератора.
- **Сборщик** — поиск и сбор сведений из подключённых заметок в отдельный файл.
- **Сборщик++** — сбор сведений с помощью трёх агентов. Модератор распределяет между ними поручения, которые можно отредактировать перед началом работы.

Для сборщиков доступны разные способы обработки файлов: все сразу, по очереди или группами.

### Грамотность

Проверка орфографии и пунктуации с помощью подключённой модели:

- проверка отдельного фрагмента с подсветкой изменений;
- проверка целого Markdown-файла с сохранением исправленной копии.

### Инструменты

- **Вариатор** — создание нескольких вариантов формулировки одного фрагмента по выбранным промптам.
- **Биография** — сбор сведений о персонаже из подключённых материалов и создание его карточки.

### Переводчик

Переводчик работает в трёх режимах:

- простой перевод вставленного текста;
- перевод отдельного Markdown-файла;
- перевод книги — нескольких файлов или папки с главами.

Можно указать язык перевода, размер чанка для обработки больших файлов и пожелания к переводу, например написание имён и терминов.

### Проекты

Каждый проект подключается к отдельной папке в хранилище Obsidian. На вкладке проектов отображаются календарь активности, статистика изменения текста и сведения о генерации.

Рабочие материалы плагина сохраняются в папке `_WriterStudio` внутри соответствующего проекта. Это обычные Markdown-файлы: их можно открывать и читать в Obsidian.

### Голосовой ввод

Плагин поддерживает диктовку через локальный сервер Whisper. Распознанный текст вставляется в поле ввода.

## Подключение моделей

Writer Studio поддерживает локальные и облачные подключения, в том числе Ollama, llama.cpp и OpenAI-совместимые API. Подключение и модель выбираются в настройках плагина.

Для голосового ввода требуется отдельно настроенный сервер Whisper.

**Приватность:** при использовании локальной модели запросы отправляются на указанный локальный сервер. При выборе облачного сервиса текст запросов и подключённые материалы отправляются этому сервису. API-ключи хранятся в настройках плагина без шифрования.

## Планы разработки

Writer Studio ещё развивается. Дальнейшая работа сосредоточена на улучшении существующих возможностей:

- удобство работы с локальными моделями и подключёнными материалами;
- развитие инструментов для работы над книгой;
- улучшение переводчика и работы с большими текстами;
- развитие проектов, виджетов и статистики;
- исправление ошибок и упрощение интерфейса.

Планы могут меняться по мере разработки и тестирования.

## Состояние проекта

Плагин находится на раннем этапе разработки. Результаты работы нейросетей зависят от выбранной модели и её настроек, поэтому переводы, исправления и собранные сведения стоит проверять.

Обратная связь и сообщения об ошибках помогут сделать Writer Studio лучше.
